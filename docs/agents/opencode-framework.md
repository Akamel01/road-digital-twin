# opencode framework for this repo

- Base branch: `main`. One issue per session, one branch and one pull request per issue, with `Closes #N` in the body.
- Claude Code reviews and merges. opencode never merges and never closes issues.
- Data is never committed. Datasets, PDFs and model weights stay out of git; the repo holds download scripts and manifests only.
- Writing rules for docs: plain English, every factual claim cited, no marketing words. Don't use "AI" in definitions or headline statements.
- Tickets that touch different files can run in parallel.
