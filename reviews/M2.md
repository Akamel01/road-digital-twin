## Required changes

R1. **The module still cannot refine anything; R1 is not closed.** The mechanical defect from round 2 (variable-length `resfun` crashing `least_squares`) *is* fixed: `_residuals_one_view` now returns a fixed-length NaN-padded vector (line 249) and both `resfun`s zero-pad (lines 358, 489); the inlier re-solves feed fixed-length vectors too (lines 411, 581-585). But round-2 R1's required verification — "base pose → `reason in {converged, no_improvement}` … injected 0.2°/2 cm → recovered within 1 cm / 0.1°, `hit_bound == False`" — fails on every scene constructed this round (see Evidence). Two defects stack:
  - **R1a (new, fatal): the cross-section scan window is hard-coded `n_side = 8` pixels** (`twin/stages/colour_pose.py:276-279`), not derived from `EDGE_SEARCH_M` (0.5 m, the constant `colour.py` itself uses for exactly this search: `n_side = int(np.ceil(EDGE_SEARCH_M / cell_m))`) nor from stripe width. At these depths 0.15 m of paint subtends 30-50 px, so the window sits entirely inside the stripe and `_cross_section_offset` returns `None` (hi-lo = 0 < `EDGE_MIN_CONTRAST`) for almost every anchor — that is why 44/51 anchors are lost. Fix: size the window in metres (`ceil(EDGE_SEARCH_M / m_per_px)`, metre offsets like colour.py's `s_grid`), and take offsets at pixel-centre spacing.
  - **R1b (new): the inlier machinery degenerates on consistent-but-biased residuals.** All-equal residuals → MAD = 0 → std = 0 → `sigma = 1e-12` (lines 398-400, 568-571) → zero inliers → deterministic `insufficient_inliers` even when the estimator is stable. Floor sigma to at least one pixel (`d/fx`), or switch the inlier test to a MAD-relative / absolute metre threshold; state the choice. And in the thin-line case the inlier re-solve's acceptance `cost_after < cost_before` passes on a 2e-10 change, emitting `applied=True, reason="converged"` for a pose that got *worse* — add a minimum meaningful improvement (or reject converged when `|final_delta|` is below noise) or the info dict lies (see R3).
  Then re-verify on a solid ray-cast synthetic (not grid-point painting) with markings at two ranges: base pose residuals ≈ 0, injected 0.2°/2 cm recovered ≤ 1 cm / 0.1°, `hit_bound == False`, pitch/z axes asserted. Keep that script in the test suite (see R2).
