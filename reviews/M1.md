## Required changes

R1. `twin/pose.py` — `hit_bound` uses a rotation **vector norm** (`np.any(np.linalg.norm(deltas[:, :3], axis=1) >= np.radians(max_deg) - 1e-6)`) while the translation side uses per-component `np.abs`. The plan's bound semantics (M2: "bounds: ±pose_max_deg (rad) for rotation ... `hit_bound` True if any |x| within 1e-6 of bound"; and the translation check right next to it) are per-delta6-component. Concrete failure: deltas with rotation (0.006, 0.006, 0.004) rad → each axis < 0.5° bound, norm = 0.0094 rad > radians(0.5°) → `hit_bound=True` even though no parameter is at a bound. Fix: `np.any(np.abs(deltas[:, :3]) >= np.radians(max_deg) - 1e-6)` (per-component, mirroring the translation check). Keep the empty-deltas path unchanged; `test_pose_report_flags_the_drive_when_a_quarter_is_off` must still pass.

## Notes (not blocking, but must not be lost)

N1. `pose_report` signature is `p: Any` with `getattr(p, "pose_flag_deg", 0.5)` etc. The defined `PoseParams` Protocol is never used, and the fallbacks silently mirror **SplatsParams** defaults (0.5/0.05 flag, 1.0/0.1 max) rather than ColourParams (0.25/0.025, 0.5/0.05). Passing a params object missing attrs silently applies the wrong thresholds. Prefer `p: PoseParams` (structural Protocol as the plan specifies) or raise on missing attrs; do not layer silent fallbacks underneath a Protocol.
N2. `applied` is hardcoded `True` and `reason` hardcoded `"converged"` for any non-empty deltas. M2 defines `applied = cost improved AND not hit_bound` with reason `converged|no_improvement|no_anchors|channel_skipped`. Nothing in M1/M2/M3 says who may override these in the frozen dict — M3 must post-process `pose_report`'s output before it reaches qa.json (or M2/M3 must extend `pose_report` then). Do not ship `zbuffer-pose-refine` QA claiming `applied: true / converged` for runs whose optimizer did not improve cost.
N3. Empty-case `reason: "no_cameras"` vs the M2 vocabulary ("no_anchors" for the n==0 path) — align before M3/M6 surface it in qa.json/tables.
N4. One-dimensional `deltas` of shape (6,) crashes on `deltas[:, :3]`. Callers pass (N,6) today (splatting passes `res["pose"][ids]`); consider `np.atleast_2d` semantics or a docstring stating the required shape.
N5. `drive_flagged` threshold 0.25 is hardcoded (matches the "quarter of cameras flagged" rule); fine as a constant, note only.
N6. Reviewer re-ran `uv run twin schema` to verify idempotence (no backup of uncommitted schemas was possible — `/tmp/opencode` is not writable here — but the diff stat was unchanged at 61+61 lines and all embedded defaults match the new contracts). Whoever merges should treat the schemas as verified-in-sync, not as unreviewed artifacts.
N7. M1 adds no tests; ownership of the recovery/wiring tests is M4 per the plan. Existing-test parity with base was confirmed by stash/re-run.
